# roboti

Trading-robot projects. Each subdirectory is a self-contained prototype;
shared conventions and skills are borrowed from other repositories as
needed rather than duplicated here.

## Projects

- [`ftmo-swing-mt4`](./ftmo-swing-mt4) -- FTMO 2-Step Swing (MT4/MQL4)
  EURUSD+GBPUSD London Range Breakout + Retest prototype: account-wide risk
  engine, offline Python research simulator, and an uncompiled MQL4 EA
  skeleton. See its own `README.md` for status and exact commands.
